---
title: "Protocol reference"
---

Send one JSON object per WebSocket **text frame**. The `type` discriminator is required and case-sensitive. Each required field must have the documented type. Invalid JSON, unknown message types, and invalid field types are logged and ignored. Binary messages are ignored. Messages and frames are limited to 1 MiB; exceeding the transport limit can close the connection.

### voice\_state

Send the complete roster when someone joins, leaves, speaks, mutes, or changes their name or color. It replaces the previous roster.

```json
{
  "type": "voice_state",
  "in_call": true,
  "members": [{
    "id": "user-42",
    "name": "Mara",
    "avatar_url": "https://example.com/avatars/mara.png",
    "color": [103, 80, 164],
    "speaking": true,
    "muted": false,
    "is_self": false
  }]
}
```

| Field | Type | Meaning |
| --- | --- | --- |
| `in_call` | boolean | Whether a call is active. False clears the roster and local mic/deafen state. |
| `members` | array | The complete list, in display order. |
| `id` | string | A stable member identifier. |
| `name` | string | Display name; its initial is the fallback avatar. |
| `avatar_url` | string or null, optional | Public HTTPS thumbnail URL, maximum 2,048 characters. Missing or failed images fall back to initials. |
| `color` | three integers | RGB values, each from 0 to 255. |
| `speaking` | boolean | Draws an active speaker border. |
| `muted` | boolean | Adds a microphone-off icon. |
| `is_self` | boolean | Marks the local user with “(you)”. |

To end a call:

```json
{ "type": "voice_state", "in_call": false, "members": [] }
```

### notification

```json
{ "type": "notification", "title": "Hello", "body": "Mara joined the call" }
```

Both fields are strings. Notifications expire after approximately eight seconds. At most five are kept, with the newest displayed first. Disabled notifications are discarded. Keep text short enough for a 320-pixel-wide card.

### mic\_state

```json
{ "type": "mic_state", "muted": true }
```

Updates the local mic display. A self member appears muted when either this value or their roster `muted` field is true. Keep both in sync when unmuting.

### deafen\_state

```json
{ "type": "deafen_state", "deafened": true }
```

Updates the control panel’s deafen display. This does not change actual audio or automatically mute the microphone.

### Control negotiation

A bidirectional integration sends this after each WebSocket connection:

```json
{ "type": "hello", "version": 1, "controls": true }
```

Only the most recently negotiated client receives controls and may update call/mic/deafen state. Other connections may still send notifications. Taking control clears the previous call until the new client publishes its snapshot. Legacy state-only integrations can continue sending the four messages above without negotiating. Call controls are disabled when no compatible client is connected or no call is active.

Yaplay sends one of these JSON text messages when a control is pressed:

```json
{ "type": "set_mute", "muted": true }
```

```json
{ "type": "set_deafen", "deafened": true }
```

```json
{ "type": "leave_call" }
```

Apply the requested state using your host's voice actions, then send the resulting roster, mic, and deafen state. The overlay does not update optimistically: microphone permissions and call roles may prevent a request from succeeding. Do not replay control requests after reconnecting. Disconnecting the active control client clears its roster and disables call controls. The Exit button still exits Yaplay rather than leaving the Yapin call.
