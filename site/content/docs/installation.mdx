## 1. Download and open

[Download Yaplay](/#download) for your computer. Downloads come directly from the latest GitHub Release.

- **Windows:** open the downloaded `.exe`.
- **macOS:** open the `.dmg`, then drag Yaplay into Applications. Choose Apple Silicon or Intel to match **Apple menu → About This Mac**.
- **Linux:** not supported yet.

macOS builds are not notarized. If macOS blocks a build you trust, open **System Settings → Privacy & Security** to review it.

## 2. Start the overlay

Open Yaplay, choose your display, and press **Start**. Leave the port at `8080` unless you need to change it. Yaplay remembers your settings and starts the overlay automatically next time.

An empty overlay is invisible. You’ll see your call once a connected integration sends it.

## 3. Connect your Yapin client

Enable a compatible Yaplay integration in Yapmod, Yap++, or your chosen modified client. Set its connection address to `ws://127.0.0.1:8080`. Both apps must run on the same computer.

This repository does not ship an installable client plugin. If your client has no integration, a developer needs to [build one](/docs/integration).

## Open settings or quit

Press **Ctrl+Shift+Y** on Windows or **Cmd+Shift+Y** on macOS. Select the gear for settings, then **Save** to apply changes. Select the exit icon to quit.

Mute, deafen, and leave-call buttons work only when your integration supports them and you’re in a call.

Need help? See [troubleshooting](/docs/troubleshooting). To compile the app yourself, see [build from source](/docs/building).
