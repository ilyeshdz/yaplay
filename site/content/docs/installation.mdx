---
title: "Install and start"
---

1.  Open [GitHub Releases](https://github.com/ilyeshdz/yaplay/releases) and choose a build for your computer.
2.  On Windows, run `yaplay-windows-x86_64.exe`. On macOS, open the matching DMG and drag Yaplay into Applications, or unzip the app bundle.
3.  Open Yaplay. Choose a display, enable or disable notifications, and set a port (default `8080`).
4.  On first launch, press **Start** to save your preferences. Later launches open the overlay automatically. The settings window closes and the local server starts. The empty overlay is invisible until your modified Yapin client sends data.
5.  Enable or configure a compatible Yaplay integration in your Yapin client modification (such as Yapmod or Yap++). Connect it to `ws://127.0.0.1:8080`. Both programs must run on the same computer.

On Apple Silicon, choose `aarch64-apple-darwin`; on Intel Macs, choose `x86_64-apple-darwin`. macOS builds are not notarized. If macOS blocks a trusted build, review it in System Settings Privacy & Security.

### Updates

Official builds check GitHub for stable updates after startup and every six hours.
Open Settings and choose **Download and install**, then **Restart Yaplay**.
Downloads are signature-verified. Yaplay never restarts automatically; finish your
call before installing or restarting. Keep it open while installation runs.

To disable background checks, turn off **Automatically check for updates** in
Settings and press **Save**. You can still check manually. The installation must
be writable; move the macOS app out of its DMG before updating. Development builds
and builds without a verification key provide a manual download link. Older
versions without the updater need one manual upgrade.

### Build from source

Install a current stable Rust toolchain (Yaplay requires Rust 1.98 or later). Windows also needs C++ Build Tools and the Windows SDK; macOS needs Xcode Command Line Tools. Windows and macOS are the release targets; no Linux release is currently provided.

```sh
git clone https://github.com/ilyeshdz/yaplay.git
cd yaplay
cargo build --release --locked
cargo run --release --locked
```

The executable is in `target/release/`. Use Ctrl+Shift+Y on Windows or Cmd+Shift+Y on macOS to open the control panel. The panel has icons for mute, deafen, leave call, settings, and exit. Select the settings icon to reopen settings; **Save** applies changes without restarting. Closing settings without saving leaves the overlay running. Exit closes Yaplay.

Mute, deafen, and leave call send WebSocket requests to a compatible integration and wait for its confirmed state. They are disabled until the integration negotiates controls and reports an active call. See [integration](/docs/integration).

Use the [appearance settings](/docs/appearance) to customize density, size, colors, placement, profile pictures, and large-call behavior.

Installing Yaplay alone does not connect it to Yapin. Your client modification needs a compatible integration. If one is not available for your host, use the [integration guide](/docs/integration) to build it.
