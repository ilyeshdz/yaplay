Yaplay shows who’s talking, who’s muted, and call notifications in a small desktop overlay. It supports **Windows and macOS**. Linux is not supported yet.

## Set up in three steps

1. [Download Yaplay](/#download) for your computer.
2. Open it and press **Start**.
3. Enable a compatible Yaplay integration in your modified Yapin client.

**You need an integration.** Yaplay does not connect to Yapin by itself. This repository does not include a ready-to-install Yapmod or Yap++ plugin. Check whether your client has a compatible integration before installing.

## Everyday use

Press **Ctrl+Shift+Y** on Windows or **Cmd+Shift+Y** on macOS to open the controls. Use the gear to change settings, or the exit icon to close Yaplay.
