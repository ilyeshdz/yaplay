---
title: "Overview"
---

Yaplay renders voice activity and notifications above desktop windows. Your application owns the call, audio, and users. An integration translates its events into JSON messages that Yaplay understands.

This is an independent project: any application can become compatible through a plugin, a wrapper, or a direct connection. Yapmod and Yapin apps are possible consumers of the same public protocol; no Yapmod runtime is required.
